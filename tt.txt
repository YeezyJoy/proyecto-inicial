--Convierte el puntaje de un área (0 a 100) en una prioridad. Por debajo de 40 
devuelve Alta, entre 40 y 69 Media, y de 70 en adelante Baja: menos puntaje 
significa más brecha digital, o sea más urgencia. Los umbrales están como 
constantes arriba para poder ajustarlos sin tocar la lógica.

UMBRAL_ALTA = 40
UMBRAL_MEDIA = 70

def severidad_por_puntaje(puntaje):
    if puntaje < UMBRAL_ALTA:
        return Prioridad.ALTA
    if puntaje < UMBRAL_MEDIA:
        return Prioridad.MEDIA
    return Prioridad.BAJA
